YOUR DATA, YOUR DEVICE

Privacy policy.

Last updated: 28 October 2026

Summary

Maize Crush — Zimbabwe Harvest is an offline crop-matching puzzle. The current game does not require an account and does not include advertising SDKs, analytics, or game telemetry. Gameplay data is saved locally on your device or in your browser and is not sent to the game developer.

Information stored locally

To keep the game working, it stores gameplay progress and settings locally, including your current level and round, scores, level stars, achievements, daily challenge history, Farm Journal counts, sound and accessibility preferences. The browser version uses browser storage; the Android app uses local WebView storage. This data is used only to provide game features.

Backups you choose to create

The game lets you export saved progress to a JSON backup file and import a backup later. Exported files are controlled by you and may contain your game progress and preferences. Store them somewhere private and share them only with people you trust. Importing a backup replaces the saved game data on that device.

Information the game does not request

The current Android app does not request access to contacts, location, camera, microphone, or advertising identifiers. It does not require an internet connection to play. The game code does not send gameplay data to an analytics or advertising service.

Website hosting

The browser version is hosted by GitHub Pages. The hosting provider may process standard technical information needed to deliver and secure the website under its own policies. This is separate from the game's locally stored progress. Read the GitHub Privacy Statement for details about GitHub's processing.

Retention and deletion

Your game progress remains in local storage until it is overwritten or you clear the app's data or the browser's site data. Uninstalling the Android app or clearing browser data may remove local progress. Keep a backup if you want to preserve it.

Children's privacy

The current game does not knowingly collect personal information from children or adults. It has no account-registration feature.

Changes to this policy

If future versions add accounts, online services, analytics, or advertising, this policy and any required in-app/store disclosures must be updated before those features are released.

Contact

For questions about this policy, use the Maize Crush GitHub Issues page.
